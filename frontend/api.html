Developer guide

Protect a file with one request.

The public API accepts one raw file and returns protected bytes in the same format. No account or API key is required for the current free demonstration service.

Request

POST https://datasentinel.ifhx.my/api/v1/protect

Send the file as the raw request body. Set X-Filename to the file name, and set an appropriate Content-Type. The response has Content-Disposition: attachment. Save the response bytes as a file; do not treat them as JSON or text.

curl --fail --request POST \
  --header "X-Filename: sample.pdf" \
  --header "Content-Type: application/pdf" \
  --data-binary @sample.pdf \
  --output protected-sample.pdf \
  https://datasentinel.ifhx.my/api/v1/protect

Use a synthetic document for first integration tests. A successful response is HTTP 200. Uncertain extraction or incomplete redaction returns HTTP 422 without a protected file.

A successful response also carries a temporary, content-free receipt in headers: X-Document-Type, X-Suggested-Classification, X-Detected-Categories, X-Redacted-Categories, X-Kept-Categories, X-Redaction-Hits, X-OCR-Used, X-Output-Verified, X-Processing-Ms and X-Correlation-ID. These contain category names, counts or a random request reference, never detected personal values or OCR text. Application-level error responses also carry a correlation ID; gateway-level failures may not.

X-Output-Verified: true means checks for detected values completed. It does not prove that every possible sensitive value was found. A KEEP choice deliberately leaves that category visible; the output is not PII-free. Classification is a suggestion for the sender to review, not a sharing permission.

Limits and privacy

  • Maximum input and output: 3 MiB. Scanned PDFs: up to three pages.
  • Shared free allowance: 200 requests per UTC day. HTTP 429 means the daily allowance is exhausted. This is a shared demonstration service, not a service-level guarantee.
  • Requests beyond the rate limit may receive HTTP 429. Retry later; avoid automated bursts.
  • HTTP 503/504 or a timed-out connection means no reliable result was received. Retry later with a smaller, clearer file; do not distribute an unverified output.
  • The direct processing path creates no S3 document or DynamoDB document record. Only an aggregate daily request count is kept to enforce the free allowance. AWS handles request bytes transiently under its service policies.
  • DataSentinel cannot retrieve the original or unredact the protected file. Keep the original with its sender.
  • This browser site is same-origin. Cross-origin browser integrations need a customer-side backend or a self-hosted deployment; the public endpoint does not grant wildcard CORS.

DataSentinel cannot guarantee detection of every possible sensitive value. Review protected results before sharing them.
