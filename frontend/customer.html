What happens

A short, direct workflow

01

Submit

The file travels over HTTPS to the processing API.

02

Detect

Text extraction and, for images or scans, Textract OCR identify supported fields.

03

Protect

Text or image pixels are covered. Uncertain extraction stops the result.

04

Download and review

The protected bytes return directly to your browser. A content-free processing summary appears on this page; no document catalogue is created.

This describes application storage. AWS processing and operational logs follow AWS service policies; “zero storage” cannot mean no transient processing or network transfer.

For developers

The same protection, in your application.

Send one document to the public API and receive the protected file in the response. No account or API key is required for this free demonstration service.

POSThttps://datasentinel.ifhx.my/api/v1/protect

Raw file body · X-Filename header · maximum 3 MB · 200 shared requests per UTC day

Read the full API guide ↗
Example requestcURL
curl --fail --request POST \
  --header "X-Filename: sample.pdf" \
  --header "Content-Type: application/pdf" \
  --data-binary @sample.pdf \
  --output protected-sample.pdf \
  https://datasentinel.ifhx.my/api/v1/protect

HTTP 200 returns protected file bytes. If extraction is uncertain, the API returns an error and no file.
